*再次提醒，仅在紧急情况使用手机收款功能*
1. 在手机应用商店找到cardpointe![[Pasted image 20260601081027.png]]
2. 输入账号密码登录，需要email进行注册
![[Pasted image 20260601081101.png]]
3. 左上角三条线，选择Virtual Terminal
![[Pasted image 20260601081218.png|318]]
4. 输入金额，然后点击Proceed to Payment
![[Pasted image 20260601081316.png]]
5. 选择付款方式，Credit
![[Pasted image 20260601083719.png]]
6. 输入信用卡资料，然后选择绿色键
![[Pasted image 20260601083819.png]]
7. 请客人签名
8. 客人输入邮箱后，客人的邮箱会收到收据。



# 调整或添加小费
1. 点选左上角三条线，点选Reporting.
2. 点选Tip Adjust.
3. 选择要调整小费的交易.
4. 输入小费金额，按绿色键.


# 取消单子
*请注意，交易一旦取消则不可逆，请确认取消单是正确的*
1. 选择要取消的订单
2. 在下方选择void（取消）
3. 确认取消
